# Rental Management System

A full-stack Rental Management System built with React, TypeScript, Express.js, and Microsoft SQL Server.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

### Backend
- Express.js
- TypeScript
- JWT Authentication
- Joi Validation

### Database
- Microsoft SQL Server

## Features

### Authentication
- Secure Login
- JWT Authentication
- Protected Routes
- Session Persistence

### Modules
- Dashboard (In Progress)
- Customer Management
- Item Management
- Rental Management
- Returns
- Payments
- Reports
